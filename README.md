# Venkatesh Gardas

Product manager in Fairfax, Virginia. Six years across fintech, e-commerce and
enterprise software, starting in support and ending up deciding what gets built.

Most of what I build is private, because it runs in production for people who
did not sign up to be somebody's portfolio. The writeups are public instead.

### Things I build

**[PitStop](https://venkateshgardas.com/pitstop)** Garage management for Indian
workshops. Job cards, customer approvals by link, GST invoicing and UPI
collection, live at a working garage every day. There is a demo you can click
and approve.

**[Hey Saathi](https://venkateshgardas.com/saathi)** A voice companion for
elderly Indian users, in Malayalam, Telugu, Hindi and English. No login, and a
setup a son can finish from another continent.

**[Roko](https://venkateshgardas.com/roko)** Home security hardware for the
Indian market, priced for a family that has never bought a security system
before.

**[Resume Roast](https://roast-resume-lilac.vercel.app/)** Paste a resume, pick
a heat level, get it torn apart honestly. Built in a weekend, which was its own
kind of scope lesson.

### How I build them

[**Building with AI**](https://venkateshgardas.com/ai) is the long version: the
six model surfaces running in production, how a photographed bill from another
garage becomes a row, why none of it can be steered by what is written on the
page, and the four things I cannot yet prove.

The short version is one rule. The model does the one job only a model can do,
and code does everything that has to be right. In PitStop that works out at
nearly one line in five existing only to check the other four.
